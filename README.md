# TT Alarm Bot

Send a screenshot of a table tennis match and get an alarm a set number of minutes before it starts.
Screenshots are read by Google Gemini (free tier).

## Use it
1. Open the site and click **AI settings**.
2. Paste your free Gemini API key from https://aistudio.google.com/apikey and save.
3. Paste (Ctrl+V), drop, or attach a match screenshot.

Your API key, alarms and screenshots are stored only in your own browser (localStorage).
They are never saved to this repository. Keep the tab open for alarms to ring.
